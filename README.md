# 🌐 Responsive Navbar

A fully responsive navigation bar built using **HTML**, **CSS**, and a touch of **JavaScript**. This is a beginner-friendly project designed for learning layout responsiveness, interactivity, and modern UI techniques.

## ✅ Features

- 📱 **Responsive Design** — Looks great on mobile, tablet, and desktop.
- 🍔 **Hamburger Menu** — Menu toggles on smaller screens.
- 🎬 **Smooth Animation** — Menu slides in/out with transition.
- 📌 **Sticky Navbar** — Stays fixed at the top on scroll.
- 🎨 **Hover Effects** — Stylish underline and color change on link hover.
- ⭐ **Font Awesome Icons** — For better visual clarity.

---

## 💻 Technologies Used

- `HTML5`
- `CSS3` (Flexbox, Media Queries, Transitions)
- `JavaScript` (for menu toggle)
- `Font Awesome` (via CDN)
